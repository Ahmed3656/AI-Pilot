# Autonomous Web Testing MVP Acceptance Matrix

This matrix is the verification index for `docs/testing-mvp-contract.md` version 1.0.0. `Automated` means a deterministic test is required in the owning component. `Manual` means an explicitly observed acceptance step is also required. A contract row defines the target; it is not evidence that a follow-up component already complies.

Owner labels are **API**, **Worker**, **Web**, **Infra**, **Security**, and **Integration**. Automated tests use local fixtures, fakes, and network-denied test environments. Manual verification never authorizes a prohibited live action.

## Required domain-family coverage

The first row for each family traces every operation in that family; the remaining rows trace its lifecycle, isolation, immutability, and explicit manual gates. Operation tests cover strict request/response validation, permission, tenant/project/environment lookup order, tenant-first 404 behavior, idempotency for public POST, pagination for lists, optimistic concurrency for mutable resources, stable errors, and emitted payload mappings.
